# MCPIndexSearch branding source

`mcp-index-search-icon-ai.png` is the approved, unmodified RGBA reference asset. Its SHA-256 is:

```text
CA7E1B09F1551F4D41951D54DAD3D03DF57DDDFAFB44A1FAF01F9F822A2AADC5
```

The Windows application and installer use `src/App.UI/Assets/mcp-index-search.ico`. It was derived by cropping only fully transparent outer pixels, placing the artwork on a square transparent canvas with a uniform margin, and resizing without recoloring or changing the visual content. The ICO contains 16, 24, 32, 48, 64, 128, and 256 pixel RGBA frames.
