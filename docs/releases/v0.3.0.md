# Context Mole v0.3.0

Context Mole v0.3.0 adds clearer project status, durable document issues, safer index upgrades, and more reliable evidence across mixed document formats.

## Project status and document issues

- Project summaries distinguish available search coverage, active indexing, queued work, and unresolved failures. Stale status is labelled with its last successful check instead of appearing current.
- Document issues are grouped by source file, including failures inside email attachments and archives. Larger issue lists support paging and path filtering while keeping the total scope visible.
- Retry keeps an unresolved issue visible until a successful result replaces it. Hide affects only that issue's visibility, with Undo; unchanged failures remain hidden after a retry, while changed source content can surface a new issue.
- Exclude removes a chosen file's indexed evidence and pending work without modifying the source file. Exclusions persist across restarts and atomic file replacement. Include removes the exclusion and queues fresh indexing.
- Startup and recovery screens keep error details and local recovery paths available. Keyboard project reordering preserves selection and focus through repeated moves.

## Model, OCR, connection, and update feedback

- Semantic search uses the pinned Granite Multilingual 97M model. Download, validation, cancellation, and failure states explain their effect on search; existing verified model files are retained safely.
- OCR progress and failures explain which files are affected. Unsupported platforms and unavailable models are identified explicitly rather than presented as complete coverage.
- Optional AI clients remain neutral until chosen or configured. Connection actions preserve unrelated settings, surface conflicts, and explain the local configuration changes they make.
- Installed Windows builds provide clearer update progress, retry, failure details, and the last attempted check. Restart remains deferred while indexing is active.

## Search and mixed-format evidence

- Structured search and evidence responses expose clearer source, attachment, location, confidence, and retrieval information, with bounded context and two previews by default.
- Recognized spreadsheet dates include canonical dates alongside raw serial values. Uncached formulas remain labelled as formulas instead of inventing a calculated result.
- Standalone and attached image OCR uses bounded context grouping. Frozen mixed-format fixtures cover documents, spreadsheets, images, email, attachments, and repeated evidence.

## Local-data upgrade

This release upgrades the local database to schema 9 and introduces the current extraction preparation. Existing project and folder configuration is retained. Source-backed re-extraction may run in the background; retained active evidence remains available until a successful replacement commits, including through paused projects or a failed rebuild.

Older semantic vectors are used only when both their model policy and extraction preparation are compatible. Keyword and literal evidence remain available while semantic coverage is repaired. Startup removes only allowlisted retired 311M installer-cache files under the managed-cache policy; other models, unknown cache files, and source files are preserved.

These safeguards do not recover evidence already deleted by an earlier application version. The bundled [index upgrade and recovery guide](https://github.com/JPCodeCraft/Context-Mole/blob/v0.3.0/docs/LEGACY-INDEX-UPGRADES.md) describes the boundaries. Older releases may reject an index already upgraded to schema 9; keep an index backup before attempting a downgrade.

## Install and update

Download [JPCodeCraft.ContextMole-win-x64-Setup.exe](https://github.com/JPCodeCraft/Context-Mole/releases/download/v0.3.0/JPCodeCraft.ContextMole-win-x64-Setup.exe) for Windows 10+ x64. Existing installed Windows builds can obtain this release through their normal update check.

Windows releases remain unsigned, so SmartScreen may show an unrecognized-app warning. This release provides a Windows x64 installer and update packages; native Linux and macOS packaging is not included.
