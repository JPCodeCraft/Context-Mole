# Context Mole v0.2.5

Context Mole v0.2.5 keeps meaning-based search available while projects transition between embedding policies and makes partial semantic coverage visible and repairable.

## Mixed embedding search

- Semantic and hybrid searches continue using documents whose embeddings match the active model instead of disabling semantic retrieval for the entire project.
- Hybrid keyword retrieval still covers the full searchable index while the semantic branch searches only the compatible subset.
- MCP responses report `semantic_partial_coverage` with compatible, excluded, and repair status details when coverage is mixed.
- If no compatible embeddings exist, semantic search remains unavailable and hybrid search safely falls back to keyword results.

## Coverage status and repair

- The project screen shows how many indexed files currently have compatible embeddings.
- The status distinguishes partial coverage from repairs that are already queued in the background.
- A focused repair action queues only files with missing, incomplete, or outdated embeddings; keyword data and source files are not rebuilt or modified.
- Background policy refresh now evaluates compatibility against the active embedding model so mixed generations converge automatically.

## Reliability

- Vector snapshots and streaming semantic retrieval are scoped to one explicit embedding policy, preventing incompatible vectors from entering the same search branch.
- Automated coverage verifies that compatible documents remain semantically searchable while legacy documents remain available through keyword search and await repair.
