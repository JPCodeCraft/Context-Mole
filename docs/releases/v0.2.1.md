# Context Mole v0.2.1

Context Mole v0.2.1 polishes project management and fixes Windows start-at-sign-in behavior.

## Project management

- Reorder projects from the sidebar with a dedicated drag handle. A floating card preview follows the pointer while surrounding projects animate around the open drop position.
- Project order is saved locally and restored after restarts. Background refreshes no longer reset the chosen order, and newly created projects are appended safely.
- The empty-project plus control is now a functional, centered **Add project** button.

## Interface polish

- Inputs now retain the app's dark surface and blue focus treatment instead of adopting a black or system-accent focus background.
- The app uses a consistent blue accent throughout, including active-indexing controls.
- Project content keeps a stable width when active-indexing details are expanded or collapsed.
- Expand and collapse chevrons now use the same shape and rotate consistently.
- Modal windows load the embedded Context Mole icon reliably.

## Windows startup

- Start-at-sign-in now registers Velopack's stable root launcher, so the entry continues working after an application update.
- Automatic launches start quietly in the system tray, while normal launches continue to open the main window.
- Startup registration is flushed and verified immediately, with clearer failure reporting if Windows does not retain the entry.

## Install

Download [JPCodeCraft.ContextMole-win-x64-Setup.exe](https://github.com/JPCodeCraft/Context-Mole/releases/download/v0.2.1/JPCodeCraft.ContextMole-win-x64-Setup.exe) for Windows 10+ x64. Releases are currently unsigned, so Windows SmartScreen may show an unrecognized-app warning.
