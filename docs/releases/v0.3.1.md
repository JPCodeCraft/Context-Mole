# Context Mole v0.3.1

This patch keeps indexing progress readable while work is running and makes successful work easier to see.

## Stable indexing status

- The live indexing panel has a fixed layout, so rapid item updates do not push project content up and down.
- Inventory and search coverage keep their last verified values while a refresh is pending. A routine refresh no longer clears the cards or flashes a loading state on each poll.
- Progress shows actual successful jobs completed during this app session, with the last successful completion date and time. This is a job count, not a unique-file total, and it resets when the app restarts.
- Queued, running, paused, CPU-waiting, retrying, and failed work remain distinct. Existing indexed coverage can stay unchanged while a repair is in progress.
- Startup text now distinguishes routine index checks from upgrades that are needed.

## Install and update

Download [JPCodeCraft.ContextMole-win-x64-Setup.exe](https://github.com/JPCodeCraft/Context-Mole/releases/download/v0.3.1/JPCodeCraft.ContextMole-win-x64-Setup.exe) for Windows 10+ x64. Existing installed Windows builds can obtain this patch through their normal update check.

This patch does not introduce a database schema or extraction-layout migration. Windows releases remain unsigned, so SmartScreen may show an unrecognized-app warning. Native Linux and macOS packages are not included.
