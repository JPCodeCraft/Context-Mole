# Context Mole v0.2.9

Context Mole v0.2.9 fixes MCP connections launched by Windows MSIX clients reading a separate, stale copy of the desktop index.

- Detects Windows AppData redirection before accessing the index, broker authentication, or lifecycle files.
- Automatically starts the MCP server in the same user's desktop runtime while preserving the client's stdio connection and environment settings.
- Uses private named pipes, keeps diagnostics on stderr, and releases the worker when the client disconnects.
- Isolates the updated shared broker from legacy brokers that may still be using a private cache.
- Logs the requested and physical data directories and the running MCP version to make future path problems visible.

Your existing index, models, and settings remain in their current directory. Update Context Mole and reload your AI client's MCP connection; no reindex or configuration change is required.

Download [JPCodeCraft.ContextMole-win-x64-Setup.exe](https://github.com/JPCodeCraft/Context-Mole/releases/download/v0.2.9/JPCodeCraft.ContextMole-win-x64-Setup.exe) for Windows 10+ x64.
