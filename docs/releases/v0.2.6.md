# Context Mole v0.2.6

Context Mole v0.2.6 makes OCR deadlines fair under processor contention and clarifies how project dashboard totals relate to one another.

## OCR reliability

- OCR timeouts now begin only when a request has processor capacity, owns the serialized OCR slot, and is ready to run inference.
- Time spent downloading or preparing models, waiting behind another OCR request, or waiting for processor capacity no longer consumes the OCR deadline.
- Cancellation from pausing, shutdown, or the indexing pipeline continues to interrupt waits and active OCR promptly.

## Clearer project totals

- The dashboard now labels successfully indexed files as **Searchable now** and error records as **Unresolved issues**.
- A concise explanation and detailed tooltips clarify that total files is a unique file count, searchable files can overlap queued or processing work while their last good index remains available, and one file can have multiple unresolved issues.
