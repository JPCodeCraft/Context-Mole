# Context Mole v0.2.3

Context Mole v0.2.3 fixes background-start window restoration on Windows and restores safe parallel document parsing.

## Windows startup and tray

- Automatic launches still start quietly in the system tray, but the initial hide is now one-time.
- Showing Context Mole from the tray now keeps the window visible, including after it has previously been shown and closed back to the tray.

## Parallel indexing

- PDFs, images, Office files, email messages, and archives can now enter extraction concurrently when the selected CPU profile and available memory allow it.
- Memory admission reserves one shared OCR peak instead of serializing every document that might contain OCR-capable content.
- OCR peaks remain serialized and account for every active document reservation, preserving the operating-system safety reserve.
- OCR workers yield their normal processor slot before requesting full OCR capacity, preventing processor and memory admission from waiting on each other.
- Activity details now distinguish serialized OCR waits from ordinary process or system-memory limits.

## Install

Download [JPCodeCraft.ContextMole-win-x64-Setup.exe](https://github.com/JPCodeCraft/Context-Mole/releases/download/v0.2.3/JPCodeCraft.ContextMole-win-x64-Setup.exe) for Windows 10+ x64. Releases are currently unsigned, so Windows SmartScreen may show an unrecognized-app warning.

For the complete search schema, examples, data behavior, and manual MCP setup, see the [README](https://github.com/JPCodeCraft/Context-Mole#agent-directed-search).
