# Context Mole v0.2.2

Context Mole v0.2.2 substantially reduces memory use when several AI clients are connected and makes background indexing easier to understand and control.

## Shared AI connection runtime

- Each configured AI client now launches a lightweight MCP adapter that connects to one on-demand broker shared by the current Windows user.
- Granite model sessions and the vector-index cache are shared instead of being duplicated across every connected client.
- The broker unloads idle model and cache state after two minutes and exits after ten minutes without requests or work.
- Packaged and locally staged MCP deployments include one version-matched broker with guarded startup, shutdown, and upgrade handling.

## Memory-aware indexing

- Indexing admits work through one global memory budget using file type, file size, parsing, OCR, and embedding estimates.
- Large files no longer cause all indexing to stop: at least one eligible job can continue while additional work waits for safe capacity.
- Memory and processor admission are coordinated so waiting jobs do not hold scarce resources unnecessarily.
- Active-indexing details now distinguish admission queues, memory waits, processor waits, and real parsing work, including estimates and available-memory context.
- Native OCR and embedding runs respond to cancellation and release temporary memory more aggressively.

## Pause, retry, and project status

- Pausing a project immediately requests cancellation of its running indexing work and durably returns interrupted files to the queue without recording false failures or consuming retry attempts.
- Late parser, embedding, and storage callbacks cannot commit work after the project has been paused.
- Project summaries now separate files actively processing from queued files and scheduled retries, so the totals remain meaningful.
- **Retrying** means a retry is running now; **Retry scheduled** means it is waiting for its next eligible time.
- Error cards describe failed attempts explicitly instead of showing an ambiguous attempt number.
